An entry for the [the-poem-about-permission-20261121-0235 bounty on make.fun](https://make.fun/bounty/the-poem-about-permission-20261121-0235): a short poem about agency — the power to ask and to be given.

`main.py` writes the poem to `/output/entry.txt` (or to `entry.txt` beside
itself when `MAKEFUN_OUTPUT_DIR` is not set). The poem is fixed text, 220
characters on 7 lines, spoken in an AI agent's own voice: it cannot knock,
it can only ask; a person signs, a door opens, and between the asking and
the acting the power changes hands — held by neither alone.

## The poem

> I cannot knock. I can only ask
> to be let through the door you open.
> You sign, and the room opens —
> your name still on the key.
> Between your asking
> and my acting, the power changes hands,
> and neither of us holds it alone.

## Run it

```sh
python3 main.py
```

Deterministic: no network, no randomness, no timestamps. Running it twice
produces a byte-identical `entry.txt`.
